# FAQAT MIJOZ EXCEL HISOBOTI QO‘SHIMCHASI

Faqat shu paketdagi fayllarni GitHub'dagi aynan shu yo‘llarga joylang. Qolgan fayllarga tegmang. Railway yangi commit bo‘yicha deploy qiladi. Yangi migratsiya kerak emas.

Hisob va qarzlar → Mijoz bo‘yicha chiroyli Excel hisobot → mijozni tanlang → Excel yuklab olish.

Yangi export faqat moliyaviy huquq berilgan kameralardagi tanlangan mijoz ma’lumotlarini chiqaradi. Barcha mijozlarni birdan yuklab olish yangi tugmada mavjud emas. Eski CSV linki o‘z holicha qolgan.

Yangi dependency: XlsxWriter. Railway build paytida requirements.txt orqali o‘rnatiladi.

Xavfsizlik: eski GitHub commitni saqlang; deploy muvaffaqiyatli bo‘lgach yangi xlsx funksiyasini tekshiring. Boshqa tizim modullari o‘zgartirilmagan.
